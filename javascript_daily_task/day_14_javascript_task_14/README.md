# 📝 To-Do List

A simple **To-Do List** project built using **HTML, Tailwind CSS, and JavaScript DOM**.

## 🚀 Features

* Add a new task
* Display tasks dynamically
* Click a task to delete it
* Simple and clean UI

## 🛠️ Technologies

* HTML
* Tailwind CSS
* JavaScript
* DOM Manipulation

## 📂 Project Structure

```text
todo-list/
│
├── index.html
├── script.js
└── README.md
```

## ▶️ How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Enter a task.
4. Click **Add**.
5. Click a task to remove it.

## 🎯 DOM Concepts Practiced

* `querySelector()`
* `addEventListener()`
* `createElement()`
* `textContent`
* `className`
* `append()`
* `remove()`
