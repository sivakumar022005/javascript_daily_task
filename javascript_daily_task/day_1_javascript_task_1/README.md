# JavaScript Positive or Negative Number Checker

A simple HTML and JavaScript project that checks whether a given number is **positive or negative** using an `if...else` statement.

## 📌 About

This project demonstrates a basic JavaScript conditional statement. The variable `sum1` contains a number, and JavaScript checks whether the value is greater than `0`.

* If the value is greater than `0`, it displays **"positive"**.
* Otherwise, it displays **"negative"**.

## 💻 Code Example

```javascript
var sum1 = -10;

if (sum1 > 0) {
    document.write("positive");
} else {
    document.write("negative");
}
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the HTML file in any web browser.
3. The result will be displayed on the webpage.
